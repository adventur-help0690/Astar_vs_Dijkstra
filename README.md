# A* vs Dijkstra Pathfinding Visualization
This website visualizes the A* and Dijkstra pathfinding algorithms. It allows users to create a weighted map and see how each algorithm finds the shortest path from a start point to an end point. The visualization helps users understand the differences between the two algorithms in terms of efficiency and pathfinding behavior.

## Features
- Interactive grid where users can set start and end points, as well as obstacles and weights.
- Real-time visualization of the A* and Dijkstra algorithms as they explore the grid.
- Option to switch between A* and Dijkstra algorithms to compare their performance.

## Installation
To run the visualization locally, follow these steps: 
1. Clone the repository or download the source code.
2. Open the `index.html` file in a web browser.
3. Interact with the grid to set start and end points, obstacles, and weights, then run the algorithms to see the visualization.
